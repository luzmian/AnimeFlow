# AnimeFlow V0.4.0 — 本地播放器与自动观看进度

在已确认的 V0.3.1 上继续开发，保留资料库、最近更新排序、动态日期分组、七天预计日历、追番和主题。

## Windows 现在如何运行

1. 关闭旧版服务，完整解压本包。
2. 双击 `start-preview.bat`。电脑需要已有 Python 3.10+，不需要 Node.js 或 Rust。
3. 在资料库或动态打开动漫详情，选择已确认播出日期的剧集，点击“播放本地视频”。
4. 选择你有权观看的视频，点击视频播放按钮。关闭命令窗口或按 Ctrl+C 退出软件预览。

**这一版是已构建的浏览器预览，不是 Windows EXE。** Windows 安装包尚未构建和验证。原 `start.bat` 入口也保留。

## 本轮新增

- 本地视频播放器：暂停、继续、音量、全屏、倍速；上一集/下一集切换当前已加载的可确认剧集。
- 播放时约每五秒自动保存观看进度，暂停、拖动、结束、关闭及刷新时补存。SQLite 按作品与集数分别保存。
- 历史中的本地播放记录显示“继续观看”。刷新后重新选择同一文件，恢复上次位置；不同文件从头播放。文件不会上传，也不会作为数据库附件保存。
- 中文字幕：导入 UTF-8 的 SRT / VTT，可开关字幕。
- 离线弹幕：XML / JSON 导入、滚动/顶部/底部、开关、透明度、字号、速度、25%/50%/75%/100% 区域；可合并多个文件并去重。
- 修复详情异步请求竞争时制作公司信息被基础资料覆盖的问题。

`examples/` 含合法生成的短测试视频、字幕和弹幕，可以直接验证播放器。

## 使用限制

浏览器不会在刷新后自动重新打开你的磁盘文件，因此“继续观看”需要重新选择文件；同一次启动保留最近十二次文件选择，切回已选择过的集数可复用文件。切集范围限于详情当前加载的剧集页，新集尚未选择视频时会提示选择文件，不会虚构在线片源。播放完毕的文件再次选择时从头开始。

优先尝试 MP4 / WebM。具体编码支持取决于浏览器或 Windows WebView2；MKV、HEVC 等不保证可播。音量和全屏用控制条；要在全屏保留弹幕，使用播放器上方的“全屏”按钮。示例 WebM 已实际解码验证，其他编码没有做全面兼容验证。

弹弹play在线接口需要开发者应用审核与 AppId / AppSecret。目前未配置凭证，也未接通在线搜索、匹配或弹幕下载。没有借用其他应用的密钥。官方说明：https://doc.dandanplay.com/open/

官方平台页面继续交给浏览器打开。社区播出日期和预计日程不证明平台片源已上线；软件没有提取加密视频或绕过付费限制。

## 数据与升级

Windows 数据位于 `%LOCALAPPDATA%\AnimeFlow`，请保留此目录。其他系统预览使用项目 `data/`，可通过 `ANIMEFLOW_DATA_DIR` 指定位置。追番、逐集历史、主题、当前页面和弹幕设置保存在 SQLite。旧手动记录继续兼容；升级包不包含用户数据库。

## 测试和开发

本轮验证范围与未验证项目见 `TEST_REPORT-V0.4.0.md`。源码、预构建 React 界面、测试脚本和 Windows 构建流程均包含在包内，架构说明见 `desktop/DESKTOP.md`。

Python 测试：`python -m unittest discover -s tests`。前端构建：在 `desktop/` 执行 `npm ci`、`npm run build`。

播放器浏览器测试 `tests/browser_player.cjs` 需要 Playwright、Chromium 与 FFmpeg；可用 `CHROMIUM_PATH` 指定浏览器。它生成短视频并实际解码，联网读取 Bangumi 条目，不将受控解析器检查冒充联网弹幕测试。普通使用者运行预览不需要这些测试工具。
