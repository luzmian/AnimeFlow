# 播放器自测文件

这些文件是本项目生成的测试素材，不是动漫片源。`test-video.webm` 为 FFmpeg 合成的 20 秒彩色测试图与提示音，按 CC0 提供。

打开任意有已播出剧集的动漫详情，选择一集，点击“播放本地视频”，选择 `test-video.webm` 并点击视频控制条的播放按钮。导入 `subtitle.srt` 查看中文字幕；导入 `danmaku.xml` 查看三种弹幕。勾选“合并弹幕”后可同时导入 `extra-danmaku.json`。

暂停后查看历史；刷新再点“继续观看”，重新选择同一个视频即可恢复进度。测试记录可以在历史页删除。真实使用时请选择对应剧集的合法视频；软件不会根据文件名推断或确认版权。

JSON 还支持弹弹play comments 数组格式 `{ "comments": [{ "p": "1,1,16777215", "m": "文字" }] }`；独立 JSON 数组格式见示例。XML 接受 `<d p="时间,模式,字号,颜色,...">文字</d>`。时间为秒，模式 1 滚动、4 底部、5 顶部，颜色为十进制 RGB。在线接口并未接入。
